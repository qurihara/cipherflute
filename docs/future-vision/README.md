# 未来ビジョンの動画

CipherFlute の構想の出発点（冲方丁「メトセラとプラスチックと太陽の臓器」）から描いた、未来ビジョンの短い動画です。

- `future_vision_robot_to_girl.mp4`（20秒、1280×720）
  - 前半：親が子どもにプラスチックのロボットを手渡す（クレヨン風、無音）
  - 後半：遠い未来の荒れた世界で、少女が笛を吹き、遺跡の扉が開く
- `poster.jpg` … 後半の1コマ

動画は Google の生成 AI（Gemini）で生成し、2本をフェードアウトとフェードインでつないだものです。

ProtoPedia（https://protopedia.net/prototype/9394 ）の「なぜ作ったのか」の節では、jsDelivr のアドレスで埋め込んでいる（video/mp4 として配信されるため）。
