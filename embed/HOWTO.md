# 日用品に笛を埋め込む

任意の3Dモデル（**ホスト**と呼ぶ）に、鳴る状態のまま笛を埋め込む手順である。

開発用の作業手順書を、外部の人が読める形に書き直したものである。実行環境への依存を外し、
手元の環境に固有の話（プリンタの機種、社内の置き場）を落としてある。

## 鳴るために塞いではいけない3つの空間

笛が鳴るのは、次の3つが空のまま保たれ、かつ外気に通じているときだけである。

| | 何か | どこに開くか |
|---|---|---|
| **ボア** | 共鳴する気柱 | 笛の内部（床の上） |
| **吸込口** | 息を入れる口 | 端面（長さ方向の始点） |
| **窓** | 音が出る切り欠き | 上面 |

ホストと合体させるとき、この3つを埋めてはならない。**見た目が正しくても、
ここが埋まっていれば音は出ない。**

## 核心：先に彫り抜いてから戻す

笛をホストに重ねるだけでは鳴らない。ホストの材料が笛の空洞へ入り込むためである。

**笛の外形の凸包でホストにポケットを彫り抜き、そのあとで笛を戻す。**

```python
import embed_flutes as EF

pocket = EF.carve_and_place(host_mesh, flute_mesh, transform)
```

凸包を使うのは、笛の外形そのものだと窓や吸込口の切り欠きにホストの材料が残るためである。
凸包なら切り欠きも含めて余さず彫れる。

## 向き

**印刷して鳴る向きには範囲がある。** 横置きで、窓の向きが −135度から +135度の間なら鳴る
（360度のうち270度）。真下（180度）と、縦置きで吸込口が上を向く置き方は鳴らない。

```bash
python3 orient_check.py --angle 45      # ok / ng を返す
```

**窓が真上（0度）を向く置き方を勧める。** 壁の縁に垂直に立てる置き方は造形不良が多い。

窓と吸込口は、空気に開いた方向へ向けること。ハニカム構造などの障害物の正面に窓を置かない。

## 埋め込んだあとの検査

**印刷する前に、2つの検査で確かめる。** これで鳴らない物を作ってしまう失敗はほとんど防げる。

### 1. 向きの検査

```bash
python3 orient_check.py --stl embedded.stl
```

### 2. 空洞の検査（スライスした後）

スライスして出来た実際の経路を読み、笛の空洞に材料が置かれていないかを調べる。

```bash
python3 check_cavity.py --design embedded.3mf --print sliced.gcode.3mf
```

考え方は「**笛の凸包の中にありながら、笛の実体の外にある空間**が空気の通り道である」
というものである。押出の線分を細かい点に分け、凸包に入る点だけを取り出して、
笛の実体からどれだけ離れているかを測る。

ボアは吸込口と窓で外気につながっているので「閉じた殻」としては現れない。
**殻を数える検査では見つけられない**ので、この向きで調べる必要がある。

**素地と笛が一体になっている物には使えない**（笛の形状を名前で照合するため）。
その場合は、材料の量を同じ作りの物と比べるとよい。ボアが埋まっていれば大きく増える。

## 笛の選び方

`../flutes/uniform/` の統一管長の笛を使う。**外形はすべて同じで、中の空洞の長さだけが違う。**
見ただけではどの音か分からないので、秘密を運ぶときはこちらを使う。

外形の長さがそのまま音になる版（可視長）もあるが、長さから音が読めてしまうので、
秘匿が要るときには向かない。確実に鳴らせることだけを優先するなら選択肢になる。

## よくある失敗

| 症状 | 原因 |
|---|---|
| 見た目は正しいのに鳴らない | ポケットを彫らずに重ねた。ホストの材料がボアに入っている |
| 一部の笛だけ鳴らない | その笛の向きが範囲の外。`orient_check.py` で確かめる |
| 窓の側から音が出ない | 窓の正面に障害物がある。空気に開いた方向へ向ける |
| 材料が想定の倍になる | スライス済みのファイルを再スライスした。ボアが中実になる |
