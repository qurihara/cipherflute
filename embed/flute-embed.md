# 日用品のモデルに笛を鳴るまま埋め込む

このファイルは、大規模言語モデルの助手に読ませることを想定した作業手順書である。
人が読む導入は `HOWTO.md` にある。まずそちらを読み、細かい判断が要る場面でこちらへ戻るとよい。

## 何が要るか

- Python 3。`trimesh` と `manifold3d` を入れておく。断面を描くなら `matplotlib`、
  水密でないホストを扱うなら `open3d` または `scikit-image` も要る。
- このディレクトリの `embed_flutes.py`（`carve_and_place` / `bore_hollow` /
  `opening_is_air` / `export_multiobj` / `material_depth` と、向きの行列
  `M_WINDOW_PLUS_X` / `M_WINDOW_MINUS_X`）。
- `mini10.py`（笛を作る）と `mini10/recorder-mini-c-v3-half-2-v2.stl`（笛の素の形）。
  この2つがそろって初めて笛を作れる。較正は `../flutes/calibration.json` から読む。
- 音の並びを決めるなら `../codec/cipher_codec.py`。

## 笛の座標系

素の向きは、窓が +z に開き、床が z=0、吸込口が x=0 の端面にあり、長さが +x へ伸びる。
最小の角が原点に来る。以下ではこれを「素の向き」と呼ぶ。

## 塞いではいけない3つの空間

| | 何か | どこに開くか |
|---|---|---|
| ボア | 共鳴する気柱 | 笛の内部（床の上） |
| 吸込口 | 息を入れる口 | 端面（x=0） |
| 窓 | 音が出る切り欠き | 上面（+z） |

ホストと合体させるとき、この3つを埋めてはならない。加えて次の2つを守る。

1. 吸込口と窓がホストに埋没せず、外面に露出すること。
2. 窓の正面に障害物を置かないこと。ハニカムなどの構造があるなら、窓はその反対側へ向ける。

## 手順

1. **ホストを読み込んで調べる。** `trimesh.load` で読み、Sceneなら対象の本体を選ぶ。
   どの面が外から見える面か、板や壁の厚みはいくらか、中実か肉抜きかを調べる。
   厚みは `material_depth(host, 外面の点, 内向きのベクトル)` で測る。0なら肉抜きか開口である。
   肉抜きのホストでは、笛は開口部で「面一に沈んだリブ」になり、材料に触れるところだけで融合する。
   造形にサポートが要ることがある。

2. **笛を作る。** `mini10.flute(L)` は外形の長さがそのまま音になる。
   `mini10.uniform_flute(L, L_max)` は外形を最長管に揃え、内部の仕切り壁でボアの長さを決める。
   **秘密を隠す用途では必ず後者を使う。** 前者は長さを測れば音が読めてしまう。
   外形の長さは `mini10.uniform_body_length()` で求める。最長管ちょうどにすると、
   いちばん低い音だけ閉じた端の壁のぶんボアが短くなり、実測で約1.6mm短く、半音の半分ほど高くずれる。

3. **向きを決める。** 窓と吸込口が空気に開く向きへ回す（行列式が +1 の回転行列を使う）。
   外面が空気なら窓を外面へ、外面に障害物があるなら窓を内面へ向ける。
   吸込口は、口を当てて吹ける外縁や外面に届かせる。

4. **位置を決める。** 面一に沈める（床または窓の面をホストの外面に合わせる）。
   円周上に並べるなら、軸まわりに 360÷本数 度ずつ回す。

5. **彫り抜いて戻す。** `carve_and_place(host, placed_flutes)` を呼ぶ。
   各笛の凸包でホストからポケットを彫り、そこへ笛を戻す。これでボアが埋まらない。
   笛のメッシュそのもので引いてはならない。ボアの領域にホストの材料が残る。

6. **書き出す。** `export_multiobj(host, placed_flutes, out)` で、ホストと笛を別々の
   オブジェクトとして書き出す。ホストを粗い層で速く、笛を細かい層で刷り分けられる。

## 実際に踏んだ失敗

- **ホストに重ねて結合しただけ。** ホストの材料がボアと窓と風道を埋め、鳴らない。凸包で彫り抜く。
- **窓の正面が塞がっていた。** 窓を外面へ向けたが、その外面にハニカムがあった。窓を内面へ反転する。
- **窓と空洞のあいだに薄い材料が残った。** 窓の面を空洞の壁のちょうど外側に合わせると、
  0.5mmほどの殻が残って密閉される。彫り抜きは凸包のぶんしか行わないので、この殻は自動では消えない。
  笛の背中（窓の反対側）を壁に合わせ、本体を空洞へ食い込ませる。
- **面一に置くと彫り抜きが不安定になる。** 凸包の面とホストの面が同一平面になるためで、
  彫り残しが出る（36本のうち23本のボアに材料が残ったことがある）。
  彫る道具のほうを、外へ抜ける向き（吸込口の向きと窓の向き）へ0.4〜0.6mm広げた凸包にする。
  笛そのものは動かさない。余分に彫れるのは表面のごく薄い層だけである。
- **吸込口や窓をホストの面よりわずかでも内側に置いた。** その厚みぶんの材料が被って塞がる。
  面一（0.0mm）でよい。窓だけは面一だと薄皮が残ることがあるので、0.3mmほど出しておくと確実である。
- **窓の向きを、検査が返した角度の値から組み立て直した。** 符号を取り違えて材料の側を測り、
  鳴る設計を「塞がっている」と誤って判定した。**窓の向きは角度からではなく、配置に使った
  回転行列から取る。** `R_world = 印刷姿勢の回転 @ 配置の回転` に素の向きの窓ベクトル (0,0,1) を掛ける。

## 印刷の向き

**笛はどの向きに寝かせるかで鳴るかどうかが決まる。** 実機で角度を掃引して確かめた範囲は次のとおりである。

- **横置き（長軸が水平）で、窓が真上を0度として長軸まわりに −135度から +135度なら鳴る。**
  360度のうち270度が使える。音のずれは0度の対照に対して2.4セント以内であった。
- **180度（窓が真下）は鳴らない。** 管の天井が正しく被覆されず、窓の造形も崩れる。
- **縦置きで吸込口が上は鳴らない。** 吸込口から窓への風道（高さ1.0mmの垂直な細い管）が埋まる。
- 縦置きで吸込口が下は鳴るが、低い音は狙いより約95セント高くずれ、高い音では一回の吹鳴で
  複数の基音が同時に現れる。復号に使うなら1本ずつ実機で確かめること。

**この範囲は0.08mmの層で刷ったときのものである。** 0.2mmで刷ると狭くなり、窓が真上（0度）の
ときだけ鳴らないことがある。窓の天井が橋渡しになり、層が厚いと垂れるためである。
粗い層で刷るなら窓は横向きにする。

配置したら `orient_check.py` で確かめる。

```python
from orient_check import check_orientation, check_many, report, check_mesh_tilt
r = check_orientation(R)                                             # 笛に掛けた回転行列
report(check_many([(name, dict(R=R)) for name, R in placements]))    # まとめて
```

すでに書き出した3mfを後から調べるときは `check_mesh_tilt(mesh)` を使う。
メッシュから確実に取れるのは長軸の傾きだけだが、いちばん危ない「縦置きになっている」は捕まえられる。

## 検証（数値と断面の両方を必ず行う）

- **ボアが中空か。** `bore_hollow(result, 点列)` で、床の少し上とボアの領域の点が
  結果の外にある（＝中空である）ことを確かめる。すべて真になること。
- **開口が外気に触れているか。** `opening_is_air(result, 点)` を、窓のすぐ外側と
  吸込口のすぐ外側について確かめる。
- **被りは0.02mm刻みで探す。** 1mm刻みでは0.35mmの薄い被りを見落とす。
  外へ向かって細かく点を並べ、ホストの中に入る最大の深さを出す。0.00mmでなければ塞がっている。
- **ホストと笛を結合したメッシュに contains をかけてはならない。** 殻が触れ合うと内外の判定が
  壊れ、埋まっていないボアを「埋まっている」と誤って判定する。判定はオブジェクトごとに行う。
- **窓の前が空気かどうかは、実際のgcodeでも確かめる。** モデルの上では空気でも、
  スライサが薄い殻を刷ることがある。窓の外側1〜4mmに点を並べ、`check_cavity.py` の
  `dist_to_segments` で押し出し線までの距離を測る。0.4mm以上あれば開いている。
  窓は吸込口から12〜16.5mmのところにある。
- **吸込口がどちら側かを取り違えない。** 素の向きでは吸込口が x=0 で長さが +x である。
  配置と印刷姿勢の回転を経ると、造形機の座標では吸込口が最小の側に来ることがある。
  端を間違えると、音に関係しない密閉された空洞（仕切り壁より先）を測ってしまう。
- **断面を目で見る。** 笛を長手と横に切る平面で切り、D字の断面が殻になっていること、
  窓が外へ開いていること、吸込口が外縁に開いていることを確かめる。
  断面を平面座標へ落とすと座標系がずれるので、世界座標のまま描く。

## ホストの形ごとの置き方

- **円盤の外周（放射状に寝かせる）。** 円周を本数で割り、笛を寝かせて放射状に置く。
  窓は内側へ、吸込口は円周に接するように置く。
- **薄い板や壁（鉛直に立てる）。** 厚さ2mm程度の板で連続した平面が取れない場合は、笛を立てる。
  管の長さの方向を鉛直にし、吸込口を板の上端に面一で露出させ、窓を側面の外向きに開く。
  笛の全長を板に食い込ませて凸包で彫る。内側と外側のすべての壁へ一定の間隔で分散させる。
- **円筒の穴（穴の壁へ寄せる）。** 穴の中心と径は、点が内部にあるかどうかを格子で調べて実測する。
  断面を平面へ落とす方法は座標がずれるので使わない。穴の四方に最大4本を十字に置ける。
  笛どうしの干渉は、凸包ではなく実際のメッシュどうしの重なりの体積で確かめる。

## 水密でないホスト

厳密な立体を要求する演算は、ホストが水密でないと失敗する。穴を埋めるか、格子で作り直す。

```python
vg = host.voxelized(pitch).fill()
m = vg.marching_cubes
m.apply_transform(vg.transform)      # 格子の番号を実寸へ戻す。忘れると寸法が壊れる
```

## 刷るときの注意

- **複数のオブジェクトからなる3mfを、スライサに自動整列させてはならない。**
  各オブジェクトが個別に並べ直され、笛がホストから離れる。整列を切るか、1つのメッシュに結合する。
- **笛が多いときは、笛をすべて1つのメッシュに結合するとよい。** ホスト本体と笛まるごとの
  2オブジェクトになり、オブジェクトごとの設定が2回で済む。物理的に離れていても1つとして扱える。
- **笛だけ別の設定にしたいときは、1つのオブジェクトの中の2つの部品にする。**
  オブジェクトを分けると、床に接していない笛の側が「浮いている」と判定されて刷れないことがある。
- 別の設定にこだわらないなら、ホストの充填を0にして中空で刷ると軽く速い。笛は壁2周で鳴る。
- **層の高さの設定が黙って無視されることがある。** 継承をたどらないスライサでは、
  0.08mmを指定したつもりが既定の0.2mmに落ちる。投入する前に、生成されたgcodeの層の高さと
  総層数を必ず確かめる。
